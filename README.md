# PhosSubs

This is a personal repository for the subtitles that I work on for myself. I was
initially going to make this repo private but there is really no difference to
me either way so in the spirit of open source, here it is. This is not for release
and not for any group, nor is it polished enough to be releasable.
If someone wants to take this and release, I'd advise against it but feel free to.
Just be transparent about where the subs came from. Chances are there is already
a better release out there.

Most of the time, these are just subs that already exist that I take and modify.
I am mostly a timer and typesetter so most of the modification will focus on that.

I don't expect much contributions but you are also free to create issues for
anything wrong you find or even create pull requests if you want to fix something.
If I will merge it or not is a subjective matter.

## How I Structured This Repo

An anime series gets a single folder. For example, Naruto, Shippuden, Boruto would
all go inside a single folder. All of them would also get their own sub folders.
Each of them will have this one file named `mux.py` which muxes the episodes into
the final mkv.

All of the videos will go to a same folder so if I ever find a better video and
want to use that instead, i can dump it all into a single folder, remux and then
replace my old files.

Each anime will also have their own README with more information.
